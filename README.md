# metro_card_top - physical design with a model pad ring (run PH_run06_padring)

Physical-design flow scripts and reports for the `metro_card_top` Bloom-filter accelerator
(APB interface, 78 top-level ports) on the GPDK045 (45 nm) kit, using Cadence Innovus 25.12-s079_1.
The run was made on 2026-11-06; this repository was assembled on 2026-11-07.

**Status: intermediate result, not a final submission. Read "Limitations" first.**

## Limitations

- **The SRAM macro is a placeholder.** `sram_DATA32_HASH24_BIT_COUNT9600000` was replaced by a
  macro generated by our team (160 x 119.7 um). Its size, pin positions and timing numbers are
  invented. It is not the contest macro.
- **The IO pads are team-defined models.** `PADIN`, `PADOUT`, `PADVDD` and `PADVSS`
  (`pad_model/pad_model.lef`, `pad_model.lib`, 10 x 30 um each) are simple models written by us.
  They are not foundry IO cells, carry no ESD or drive modelling, and contribute 0 to the
  power report.
- **No power pads in the final database.** The model defines `PADVDD`/`PADVSS`, and
  `scripts/power_pads.tcl` creates four of them. They were created in one session, but the final
  database (`DBS/09_filler`) holds only the 78 signal pads (no instance named `pad_v*`), and
  neither exported netlist contains a `PADVDD` or `PADVSS`. VDD/VSS exist only as core rings and
  stripes and are not connected to any supply pad.
- **No GDSII.** A valid GDSII needs the GPDK045 GDS layer map, the standard-cell GDS and the macro
  GDS; none was found on our server.
- **No signoff DRC or LVS.** The checks below are Innovus built-in checks only (`check_drc`,
  `check_connectivity`, `check_antenna`, `check_pin_assignment`). Rule decks and standard-cell
  CDL/SPICE were not available.
- **Input netlist is provisional.** `scripts/import.tcl` reads snapshot
  `snap_20261104_1117_rtle257a4e0`, the same input as the earlier run PH_run04_halo. Part of the
  RTL was rewritten after that netlist was synthesized, and the match between RTL and netlist has
  not been fully verified.
- **The scripts are reference copies, not an exact replay.** The command history of the
  Innovus sessions (`innovus.cmd*`, not included) shows `create_floorplan` was run with 40 um margins, while the
  original `floorplan.tcl` still said 10 um; the copy here was corrected to 40 um. `power.tcl`
  and `cts.tcl` still carry "PH_run02" labels, and `cts_spec.tcl` was generated in an earlier
  run (run02) and reused. Always compare against your own logs.
- **Timing is out of scope.** No timing or STA reports are included.
- The power figures use Innovus default (vectorless) activity. The report prints no unit; mW is
  inferred because the macro leakage of 1000 nW from the placeholder library appears as 0.001.

## Flow order

The flow runs in the Innovus common UI (`innovus -common_ui`); each stage saves a checkpoint under
`DBS/`.

1. `tools/install_run06.sh` - sets up the run directory and embeds `gen_pad_files.py`, which
   generates `pad_model.lef`, `pad_model.lib`, the wrapper netlist `metro_card_pad_top.v` and
   `pad_slots.tcl`.
2. `scripts/import.tcl` + `scripts/mmmc_pad.tcl` - read LEF, libraries and netlist; top module is the
   wrapper `metro_card_pad_top`, the core is `metro_card_top`.
3. `scripts/floorplan.tcl` (sources `pad_slots.tcl`) - floorplan, macro and pad placement. Checkpoint `03_floorplan`.
4. `scripts/power.tcl` - rings (Metal7/Metal8), stripes (Metal8), `route_special`. Checkpoint `04_power`.
   `scripts/power_pads.tcl` is optional and is not part of the final database (see Limitations).
5. `scripts/halo.tcl`, `scripts/place.tcl` - macro halo, placement. Checkpoint `05_place`.
6. `scripts/cts.tcl` (+ `cts_spec.tcl`) - clock tree. Checkpoint `06_cts`.
7. `scripts/route.tcl` - post-CTS optimization, tie-offs, routing, post-route optimization, fillers. Checkpoint `09_filler`.
8. `scripts/export.tcl` - writes netlists, SPEF, SDC, SDF and the reports in `reports/`.

Run the full `check_connectivity` (not `-type regular`) between stages: the `regular` mode does not
check power nets.

## Not included

- The GPDK045 files (LEF, libraries, QRC tech file, cap table). Place your own copy and set `PDK` /
  `<GPDK045_ROOT>`.
- The placeholder SRAM macro files (`sram_placeholder*.lef/.lib`) and the netlist/RTL snapshot
  referenced as `<PD_ROOT>/handoff/...` and `<PD_ROOT>/macro_PLACEHOLDER/v2`.
- The wrapper netlist `metro_card_pad_top.v`, `pad_func.sdc`, the exported results
  (netlist, LVS netlist, SPEF, SDF, SDC), databases (`DBS/`), logs, and timing reports.

Host names, user names and absolute paths were replaced by placeholders: `<PD_ROOT>`,
`<GPDK045_ROOT>`, `<user>`, `<group>`, `<redacted>`. Script comments are in Vietnamese
without diacritics.
